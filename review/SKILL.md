### CRITICAL checks

**C1 — Hardcoded colors (not design tokens)**

Hardcoded hex, rgb, or Tailwind color classes not in the design system palette. The palette is: `neutral`, `radical` (brand red), `viridian` (teal), `sunbeam`, `tangerine`, `jade`.

Grep the diff for:


Flag any that aren't in the Factorial design token mapping (`webpage/src/design-system/mappings/`).

**C2 — Missing `notFound()` locale guard**

New pages or locale-aware routes missing the `notFound()` guard pattern:
```tsx
// Required pattern for locale-gated pages:
const tld = findTldByLocale(locale)
if (!tld) notFound()
```

Grep diff for new `generateStaticParams` or page files. If any lack the `notFound()` guard, flag as CRITICAL.

**C3 — i18n violation: `<FormattedMessage>` or raw string literals**

The project uses `intl.formatMessage()`. `<FormattedMessage>` is banned.

```bash

```

Also flag any user-visible string literals in JSX that aren't wrapped in `intl.formatMessage()`.

**C4 — Missing `revalidate` on new page**

New `page.tsx` or `layout.tsx` files that fetch from DatoCMS but don't export `revalidate`. Default in Next.js is `0` (no caching) unless set. Should be `1800` (30 min) for most pages.

```bash
grep -n "export const revalidate" <<< "$DIFF"
```

If a new page file is added without `revalidate`, flag as CRITICAL.

**C5 — DatoCMS field nullability assumption**

Code accessing DatoCMS fields without null/undefined checks. Fields can be empty in CMS.

Look for patterns like: `data.heroImage.url` without optional chaining `data.heroImage?.url`.

### INFORMATIONAL checks

**I1 — `next/dynamic` on above-the-fold component**

`next/dynamic` with no `{ ssr: true }` on hero or visible-on-load components delays LCP. Flag as informational with explanation.

**I2 — DatoCMS image missing `priority`**

`<DatoImage>` or `<Image>` components in hero/above-fold positions without `priority` prop. Flag with file:line.

**I3 — ISR revalidate set very low (< 300s)**

`export const revalidate = 60` causes TTFB spikes. Flag if lower than 300 on a page that doesn't need real-time data.

**I4 — Tailwind class outside design system**

Custom `text-[#xxx]` or arbitrary values that should use design tokens instead.

**I5 — Missing responsive variant on layout change**

New flex/grid layout without `sm:` or `md:` breakpoint variants. Factorial webpage targets 375/768/1440px.

**I6 — Component in wrong layer**

- Atoms should be in `design-system/atoms/`
- Molecules in `design-system/molecules/`
- Organisms in `design-system/organisms/`
- CMS sections in the module's `components/` dir

If a new component is placed at the wrong level, flag as informational.

**I7 — Documentation staleness**

If the diff changes a feature described in `README.md`, `ARCHITECTURE.md`, or `CLAUDE.md` but doesn't update that file, flag it.
